# TrainConsistManagementApp

Train Consist Management System - App-Based Learning Using Core Java & Data Structures

## About

This project is part of the **SRM STEP Program 2026** — a structured, use-case-driven learning path to master Core Java and Data Structures through building a real-world Train Consist Management application.

Each Use Case (UC) introduces a new Java concept, progressively building on the previous one.

## Use Cases

| Branch | Use Case | Concept |
|--------|----------|---------|
| [uc1](../../tree/uc1) | UC1 - Initialize Train and Display Consist Summary | ArrayList, Main Method |
| [uc2](../../tree/uc2) | UC2 - Add Passenger Bogies to Train | ArrayList Operations |
| [uc3](../../tree/uc3) | UC3 - Track Unique Bogie IDs | Set – HashSet |
| [uc4](../../tree/uc4) | UC4 - Maintain Ordered Bogie IDs | LinkedList |
| [uc5](../../tree/uc5) | UC5 - Preserve Insertion Order of Bogies | LinkedHashSet |
| [uc6](../../tree/uc6) | UC6 - Map Bogie to Capacity | HashMap |
| [uc7](../../tree/uc7) | UC7 - Sort Bogies by Capacity | Comparator |
| [uc8](../../tree/uc8) | UC8 - Filter Passenger Bogies | Stream API |
| [uc9](../../tree/uc9) | UC9 - Group Bogies by Type | Collectors.groupingBy |
| [uc10](../../tree/uc10) | UC10 - (Extended Use Case) | Advanced Collections |
